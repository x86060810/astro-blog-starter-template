## 问题背景

Windows 11 自诞生以来，就有大量用户反馈使用卡顿。为了解决这个问题，作者尝试了好多方法，今天终于把它解决了。

Windows 11 于 2021 年发布，从诞生的那天开始，作者身边的朋友及公司同事不断反馈：使用 Windows 11 的笔记本电脑，不论是新电脑还是旧电脑，总会出现卡顿、不流畅的问题。

近年来硬件厂家出厂自带 Windows 11，为了解决这个问题，作者通常都会使用重装系统来解决。但是这种方法有一个问题：**新硬件不能完全支持 Windows 10 操作系统**，这让作者非常困扰。

最近作者发现网上关于关闭 VBS 的讨论越来越多，只要关闭它，你的电脑就能运行飞快，**提速 30%**！今天就跟着作者来实操，教大家如何关闭让人讨厌的 VBS。

## VBS 有什么用处？

**基于虚拟化的安全（VBS / Virtualization‑Based Security）** 是 Windows 11 核心安全组件，默认启用。它利用硬件虚拟化（Intel VT‑x/AMD‑V）与 Hyper‑V 虚拟机监控器创建隔离的 "虚拟安全模式（VSM）"，为关键安全功能提供独立执行环境，即使内核被攻陷也能保护核心资产。

### 核心用途

- **托管内存完整性（HVCI）**：在内核外验证驱动 / 系统文件签名，阻止未授权内核代码加载，防止内存篡改
- **隔离敏感数据**：保护凭据、加密密钥、身份认证等，避免被内核级恶意软件窃取
- **支持安全功能**：为 Credential Guard、Device Guard、Windows Hello 等提供底层隔离环境

## 如何关闭 VBS？

### 步骤一：以管理员身份运行 PowerShell

可以在操作系统的搜索框中输入 `PowerShell`，或者右键点击 Windows 图标，点击 **Windows PowerShell（管理员）**。

### 步骤二：执行关闭命令

复制下方代码粘贴到 PowerShell 运行界面中，按回车键执行：

```powershell
bcdedit /set hypervisorlaunchtype off
```

### 步骤三：重启电脑

看到操作完成后，**重启电脑**，设置即生效。

---

> ⚠️ **注意**：关闭 VBS 会提升系统性能，但也会降低部分安全保护。请根据自己的使用场景权衡利弊。如果你主要进行日常办公、游戏等使用，关闭 VBS 通常是可以接受的。
